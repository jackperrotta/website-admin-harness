# Businesses in ChatGPT

Enable the built-in `chatgpt-business` module explicitly on the pilot admin. Import only the public profile from the website harness inspection and bind its URLs to the exact website origin. The Settings endpoint requires the installation owner for reads and writes and the normal admin Origin check for writes. D1 stores the three selected statuses, the last-checked date, and the revision under the installation and site IDs. No additional Cloudflare binding or website API permission is required.

Analytics requests the optional ChatGPT report through the existing `analytics:read` grant. Production Leads uses the existing `leads:read` grant. The pilot collector stores the traffic enum on eligible live pageviews, and the inquiry Worker writes its enum atomically with first acceptance. Each database receives its own additive migration.

Prepare the source, archives, and isolated local checks for review. Review each database backup, migration, Worker, and the gated website build separately before rollout.
