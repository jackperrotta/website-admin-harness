# Client-approved reporting pairing

Implement contract v1 and both issuer and consumer for Add website → client-owner approval. Initially the private Vitris consumer is the only trusted peer configured on an issuer. Reusable packages contain no business identities, credentials or rollout records. New reporting uses a client-admin proxy with only status/analytics reads, PKCE, signed requests, pinned installation keys, bounded exchanges, durable retry receipts and per-request grant/organization checks. Human membership changes do not revoke organization reporting. Disconnecting/replacing the organization does revoke pending pairings and grants permanently.

Issuer is explicitly enabled by `webmaster` plus `reportingPairing.trustedWebmasters` in the installation manifest. Optional migration: `modules/webmaster/migrations/0012_reporting_pairing.sql`; secret `WEBMASTER_PAIRING_KEY` encrypts short-lived codes/retry receipts. Consumer migration: Vitris `modules/websites/migrations/0014_approved_pairing.sql`; retain `WEBMASTER_SETTINGS_KEY` and add private `WEBMASTER_PAIRING_SIGNING_KEY` (P-256 JWK). All rows bind installation/site/exact admin origin. No runtime tables, key generation, initial seeding, remote migration or deployment.

Preserve legacy bindings, billing, users, password verifiers, mail and existing entry points. YHR remains deferred and is never requested. Use a local packed candidate for both projects, verify hostile/replayed/expired/cross-audience requests, retry/rotation, individual removal versus organization revocation, cache/pause fencing, browser approval and external package consumption. Run both project checks. Deliver installation/backup/key-recovery and rollback instructions with no automatic live activation.

Matching packed 1.2.0 runtime/contracts were installed in the private Vitris consumer; its 31 tests, production builds and desktop/mobile pairing, Websites and billing browser checks passed.

No npm publication, production key installation, remote migration, deployment or real client connection was performed for this candidate. Candidate archives and integrity receipts remain private to the Vitris installation.
