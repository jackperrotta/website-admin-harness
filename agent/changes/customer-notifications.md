# Confirmation emails and customer appointment management

Add a new additive migration 0007; preserve 0001-0006. Explicit admin notification/capture mode and snapshotted customer cutoff rules control new appointments. Native writes enqueue durable email work transactionally. Build text/HTML messages with the existing stable-UID calendar attachment. Use Cloudflare Email Service's structured builder; test-mode send requires an explicit recipient allowlist. Captures and prepared messages are encrypted. Provider acceptance is not mailbox delivery; ambiguous sends stop for review instead of automatically duplicating email.

Email links carry high-entropy, hashed, appointment-only capabilities in URL fragments. The website strips fragments before other scripts and exchanges them after an explicit user action for short-lived in-memory bearer sessions. No GET or link scanner may change an appointment. Customer commands have an independent scoped transaction guard, revisions, idempotency and cutoff checks, preserve snapshots and original reservations on failed reschedules, and enqueue the same calendar/email jobs. Cancellations revoke capabilities. Pausing new bookings still permits eligible cancellation; rescheduling respects the scheduler's pause.
