# Local billing prototype

Implement opt-in `billing` and `account-billing` trusted modules for isolated loopback installations only. A seller preview on 127.0.0.1 owns a synthetic D1 ledger; a separate client preview on localhost has its own authentication database, independent browser cookies, and a fixed local service binding that exposes only the Alder customer account. This binding is a preview adapter, not production pairing or Stripe integration. No external fetch, email, Stripe credential, cloud provisioning, or remote migration is involved.

Add owner-only billing capabilities, an optional prototype migration scoped by installation and site, optimistic revisions, bounded validated commands, and repeatable command receipts. Compile a dedicated React workspace with overview, customers, subscriptions, invoices, payments, plans, setup states, and client self-service. Keep the existing portfolio and ordinary manifests unchanged; add a dedicated example installation and explicit preview command.

Verify disabled and unauthorized access, production/remote-backend refusal, customer isolation, stale/concurrent/repeated commands, draft-versus-sent invoice behavior, desktop/mobile interactions, and consumption from packed packages outside the workspace. Run `npm run check`. The prototype uses sample invoice documents and simulated financial actions, clearly labeled in both views.

Validation completed November 4, 2026: `npm run check` passed all 158 tests, including eleven billing server/browser tests and seller/client consumption from packed packages outside the workspace. Desktop and phone screenshots were visually inspected under ignored `artifacts/billing-prototype/`. Browser coverage verifies independent logins, editing and sending a draft, client payment reflected in the seller view, plan changes, cancellation/reversal, card simulation, paused states, and ordinary installations that never request or load billing. The local review servers run on 127.0.0.1:4394 and localhost:4395. No Stripe connection, production deployment, or remote migration was performed.
